# FreeMessanger — клиент-серверный чат в терминале

Простой многопользовательский чат с клиент-серверной архитектурой, написанный на C.
Сервер принимает подключения и рассылает сообщения всем остальным клиентам,
а клиент предоставляет псевдографический интерфейс в терминале на базе `ncurses`.

## Возможности

- Асинхронная обработка каждого клиента в отдельном потоке (`pthreads`).
- Рассылка (broadcast) сообщений от одного клиента всем остальным.
- Терминальный интерфейс клиента: отдельное окно чата и окно ввода.
- Передача ника клиента при подключении, имя отображается в сообщениях.
- Поддержка IPv4 и IPv6 (через `getaddrinfo` / `AF_UNSPEC`).

## Зависимости

- Компилятор `gcc` (стандарт C)
- `make`
- Библиотека `ncursesw` (интерфейс клиента) — в Debian/Ubuntu: `libncurses-dev`
- `pthreads` (входит в стандартную `glibc`)

Установка зависимостей (Debian/Ubuntu):

```bash
sudo apt install gcc make libncurses-dev
```

## Сборка

Собрать всё (клиент и сервер):

```bash
make all
```

Собрать только клиент или только сервер:

```bash
make client
make server
```

Готовые бинарники попадают в каталог `build/`:

```
build/client
build/server
```

Очистить результаты сборки:

```bash
rm -rf build
```

## Запуск

Порт задаётся в `common/include/protocol.h` константой `PORT` (по умолчанию `8082`).
Сервер слушает его на всех интерфейсах (`AI_PASSIVE`).

### Запуск сервера

Через `make`:

```bash
make up_server
```

Или напрямую:

```bash
./build/server
```

При успешном старте в консоль выводится:

```
server: waiting for connections...
```

Сервер принимает до 10 одновременных подключений (см. `BACKLOG` в `Server/src/server.c`).

### Запуск клиента

Через `make` (хост передаётся через переменную `ARGS`):

```bash
make up_client ARGS="<HOST> <NICKNAME>"
```

Или напрямую:

```bash
./build/client <HOST> <NICKNAME>
```

Пример:

```bash
./build/client localhost ivan
```

## Параметры клиента

Клиент принимает **ровно два** позиционных аргумента (порядок важен):

| №  | Параметр    | Обязательный | Описание                                                                 |
|----|-------------|--------------|--------------------------------------------------------------------------|
| 1  | `<HOST>`    | да           | Адрес сервера: доменное имя (`localhost`, `example.com`) или IP (`127.0.0.1`, `::1`). Порт задаётся в коде (`common/include/protocol.h`). |
| 2  | `<NICKNAME>`| да           | Ник пользователя. Передаётся серверу первым сообщением и используется как префикс в чате. |

Правила:

- Если передано не ровно 2 аргумента (без учёта имени программы), клиент
  печатает `Bad init argumens` и завершается с кодом `1`.
- Порт **не** передаётся аргументом — он фиксирован константой `PORT`
  в `common/include/protocol.h` (по умолчанию `8082`) и должен совпадать у клиента и сервера.

Примеры:

```bash
# подключиться к локальному серверу с ником alice
./build/client localhost alice

# подключиться по IP
./build/client 192.168.0.10 bob
```

## Использование

После подключения открывается терминальный интерфейс:

- **Верхнее окно** — история сообщений чата.
- **Нижнее окно** (`>`) — поле ввода сообщения.

Управление:

| Клавиша            | Действие                          |
|--------------------|-----------------------------------|
| `Enter`            | отправить сообщение               |
| `Backspace`        | удалить последний символ          |
| любые символы      | ввод текста сообщения             |

Сообщения от других участников отображаются как `<ник>: <текст>`,
собственные отправленные сообщения — как `me: <текст>`.

## Коды возврата

Клиент (`./build/client`):

| Код | Значение                                   |
|-----|--------------------------------------------|
| 0   | штатное завершение                         |
| 1   | неверные аргументы командной строки        |
| 2   | ошибка разрешения адреса (`getaddrinfo`)   |
| 3   | не удалось подключиться к серверу          |
| 4   | ошибка отправки сообщения                  |

Сервер (`./build/server`):

| Код | Значение                          |
|-----|-----------------------------------|
| 0   | штатное завершение                |
| 2   | ошибка разрешения адреса          |
| 3   | ошибка `bind`                     |
| 4   | ошибка `listen`                   |

## Ограничения

- Максимум **10** одновременных клиентов на сервере (`BACKLOG`).
- Максимальный размер одного сообщения — **1024** байта (`MAX_BUF_SIZE` в `protocol.h`).
- Ник ограничен 49 символами на стороне сервера.
- Протокол пока текстовый, без бинарного кодирования и типов сообщений
  (см. планы в `common/include/protocol.h`).
